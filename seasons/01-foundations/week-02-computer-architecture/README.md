# Week 02: Computer Architecture

Understanding the fundamental structure of modern computers.

## Topics

- Von Neumann architecture
- CPU components (ALU, registers, control unit)
- Memory hierarchy
- Instruction cycle
- Assembly language basics

## Learning Objectives

- Understand how a CPU executes instructions
- Learn about registers and memory
- Explore the fetch-decode-execute cycle
- Write basic assembly code
