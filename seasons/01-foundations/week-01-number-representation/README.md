# Week 01: Number Representation

Understanding how computers represent and manipulate numbers.

## Topics

- Binary representation
- Hexadecimal notation
- Integer encoding
- Floating-point representation
- Two's complement

## Learning Objectives

- Convert between decimal, binary, and hexadecimal
- Understand limitations of number representation
- Explore overflow and underflow
