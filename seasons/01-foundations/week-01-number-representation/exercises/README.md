# Week 01: Exercises

Practice problems for number representation concepts.

## Exercise 1: Binary Conversion

Convert the following decimal numbers to binary:
- 42
- 127
- 255

## Exercise 2: Hexadecimal

Convert the following binary numbers to hexadecimal:
- 11011010
- 10101111
- 11111111

## Exercise 3: Two's Complement

Find the two's complement representation (8-bit) of:
- -5
- -42
- -128
