## Learning Method

1. Study the underlying concepts.
2. Explain them independently.
3. Implement a working solution.
4. Test assumptions and edge cases.
5. Diagnose problems and improve the solution.
6. Document the evidence and lessons.

## Documentation Standard

Every completed learning unit should include:

- Clear learning objectives
- Original technical notes
- Practical implementation or experiment
- Verification through tests or demonstrations
- Technical challenges and solutions
- Reflection and next steps
- Links to relevant code or published writing
